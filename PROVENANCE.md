# Provenance and authorship boundaries

This is an independent portfolio edition of a student-origin campus-portal concept. It is not an institutional product or endorsement. The earliest available source inspected for this edition was an exported frontend prototype; a later IT-review frontend and an independent full-stack engineering baseline were also inspected. The original exports and institutional handoff remain outside this public repository.

## What the available sources show

The early export contains navigation for a campus guide, map, daily-life help, counseling, health and emergency resources, community safety, student contacts, and feedback. Its long-form drafts express concerns about access to information, student support, privacy, boundaries, and respectful community conduct. The later review frontend changed the presentation and retained some of those drafts. The independent full-stack baseline added a modular API, database schema, authorization, and tests, while intentionally reducing sensitive support pages to fictional directory placeholders.

The static website restores selected passages from the earliest available draft exactly as text, with only rendering and whitespace adaptation. New site framing, navigation, explanatory labels, and layout are presentation work; they are not represented as original student prose. A private comparison document records withheld or unavailable material. No private source export is shipped in this repository.

## Authorship claims and uncertainty

The project owner identifies the ideas and writing as their student work. The recovered files verify the wording's presence in the earlier project, but file contents alone cannot prove who authored each sentence or whether it was drafted with assistance. The code history available here is insufficient to assign line-by-line authorship. Accordingly, this repository does not claim that every line of code, paragraph, or design artifact was written unaided by the student.

The engineering baseline and this publication preparation involved AI coding assistance for implementation, debugging, tests, and packaging. No dates or historical commit sequence are inferred from file timestamps. The copied local public baseline had no commits when this edition was prepared. The intended public GitHub repository has separate earlier history; this package does not import, alter, or make claims about that history.

## Public and private boundaries

Only institution-neutral, reviewable text and generic design concepts belong in the public edition. Names, branding, internal locations, real contacts, operational procedures, private correspondence, accounts, and source archives stay outside it. A public repository exposes code and documentation as well as the website; hiding content from a route does not make it private.

The original exported frontend used third-party no-code scaffolding and libraries. This edition does not redistribute that export or its components. It copies selected text only; rights and attribution for any further historical material require separate review. No license for this repository has yet been chosen. The full-stack code and the original writing may warrant different reuse terms.

## A traceable future history

If the owner later approves publication, an honest next set of commits could separate the public engineering baseline, the restoration of reviewed original text, and static-site preparation. These would be new commits on top of whatever public history the chosen repository already has, created in their actual order—not backdated reconstructions of the original development. Before any commit, the owner should choose a public Git author name and email and review the exact files to add. No private institutional history should be imported.
